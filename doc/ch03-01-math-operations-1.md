## plus

Функция `plus` складывает два значения и записывает результат в некую переменную.

**Стандартный вид:**

`plus name a b`

- `name` - имя переменной (имеет тип `int`, `float` или `string`), в которую нужно будет сохранить результат.
- `a` - некоторое значение или переменная (имеет такой же тип, что и переменная `var`), которое будет использоваться в операции.
- `b` - некоторое значение или переменная (имеет такой же тип, что и переменная `var`), которое будет использоваться в операции.

**Пример:**

```bash
func main
  create int a
  create int b
  set a 10
  set b 100
  plus a a b
  println a
  println b
endf
```

Вывод:

```
110
100
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.

**Сложность работы:**

При работе со `string`: O(1).

В других случаях: O(a + b), где a - количество цифр в первом числе, b - количество цифр во втором числе.
