# Переменные

Как и в любом языке программирования в UglyScript существуют переменные. Однако в UglyScript все переменные являются глобальными, и к ним можно обратиться в любом месте кода.

Теперь давайте разберём функции для работы с переменными.

## Содержание

- [create](#create)
- [set](#set)
- [delete](#delete)

## create

Функция `create` создаёт переменную определённого типа данных.

**Стандартный вид:**

`create type name`

- `type` - тип данных переменной, которую ты создаёшь.
- `name` - имя переменной, которую ты создаёшь.

**Пример:**

```bash
func main
  create int a
  create string s
  create bool f
  create float n
endf
```

Вывод:

```

```

**Ошибки:**

- Использование имени, которое уже используется для другой переменной.
- Использование несуществующего типа данных.

**Сложность работы:** O(log n), n - количество переменных в коде.

## set

Функция `set` присваивает некой переменной некоторое значение. Также функция позволяет один вектор сделать равным другому.

**Стандартный вид:**

`set name value`

- `name` - имя переменнойб значение которой ты изменяешь.
- `value` - значение такого же типа, что и тип переменной, обозначающее значение, которое нужно сохранить в переменной.

**Пример:**

```bash
func main
  create int a
  set a 10
  println a
  create string set 
  set s "hello"
  println s
endf
```

Вывод:

```
10
hello
```

**Ошибки:**

- Попытка изменить значение неинициализированной переменной.
- Попытка передать в виде значения неинициализированую переменную.
- У переменной и значения разные типы данных.

**Сложность работы:** O(log n), n - количество переменных в коде.

## delete

Функция `delete` удаляет некую переменную.

**Стандартный вид:**

`delete name`

- `name` - имя переменной, которую ты хочешь удалить.

**Пример:**

```bash
func main
  create int a
  set a 10
  delete a
  print a
endf
```

Вывод:

```
Line: 15
NameError: Variable "a" not found.
```

**Ошибки:**

- Попытка удалить значение неинициализированой переменной.

**Сложность работы:** O(1)

Для проверки правильности переменной: O(log n), n - количество переменных в коде.

## swap

Функция `swap` меняет местами значения двух переменных.

**Стандартный вид:**

`swap a b`

- `a` - имя первой переменной.
- `b` - имя второй переменной.

**Пример:**

```bash
func main
  create int a
  set a 1
  create int b
  set b 2
  swap a b
  println a
  println b
endf
```

Вывод:

```
2
1
```

**Ошибки:**

- Попытка передать неинициализированную переменную.
- Попытка передать не переменные.
- У переменных разные типы данных.

**Сложность работы:** O(log n), n - количество переменных в коде.
