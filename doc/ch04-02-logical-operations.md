## and

Функция `and` считает побитовое "и" для двух переменных типа `bool` и записывает результат в переменную типа `bool`.

**Стандартный вид:**

`and name a b`

- `name` - имя переменной (имеет тип `bool`), в которую нужно будет сохранить результат.
- `a` - переменная (имеет тип `bool`), которая будет использоваться в сравнении.
- `b` - переменная (имеет тип `bool`), которая будет использоваться в сравнении.

**Пример:**

```bash
func main
  create bool a
  create bool b
  set a true
  set b false
  create bool ans
  and ans a b
  print ans
endf
```

Вывод:

```
false
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.

**Сложность работы:** O(1)

```bash

  print ans
endf
```

```

```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
