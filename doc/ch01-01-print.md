# Функции вывода

Для того чтобы начать писать какой-либо код для начала нужно создать функцию `main`, которая будет вызываться первой автоматически.

Давайте напишем её:

```bash
func main

endf
```

Теперь внутри этой функции можно писать какой-либо код.

## Содержание

- [print](#print)
- [println](#println)
- [printf](#printf)
- [newl](#newl)

## print

Функция `print` выводит некоторую информацию.

**Стандартный вид:**

`print a`

- `a` - некоторое значение или переменная, которую нужно вывести.

**Пример:**

```bash
func main
  print "Hello, World! "
  print 1
  print 2
endf
```

Вывод:

```
Hello, World! 12
```

**Ошибки:**

- Вывод несуществующей переменной.

- Вывод вектора.

**Сложность работы:**
Если ты выводишь float: O(n), n - количество знаков до запятой.

В других случаях: O(1)

## println

Функция `println` выводит некоторую информацию и переводит на новую строку.

**Стандартный вид:**

`println a`

- `a` - некоторое значение или переменная, которую нужно вывести.

**Пример:**

```bash
func main
  println "Hello, World! "
  println 1
  println 2
endf
```

Вывод:

```
Hello, World!
1
2
```

**Ошибки:**

- Вывод несуществующей переменной.

- Вывод вектора.

**Сложность работы:**
Если ты выводишь float: O(n), n - количество знаков до запятой.

В других случаях: O(1)

## printf

Функция `printf` выводит некоторое значение типа `float`, округленное до некоторого количества знаков после запятой.

**Стандартный вид:**

`printf a n`

- `a` - некоторое значение типа `float`, которое нужно вывести.
- `n` - некоторое значение типа `int`, обозначающее количество знаков после запятой.

**Пример:**

```bash
func main
  printf 1.3333 1
  print " "
  printf 1.3333 10
endf
```

Вывод:

```
1.3 1.3333
```

**Ошибки:**

- Несуществующая переменная в аргументах.

- Первый аргумент не типа `float`
- 
- Второй аргумент не типа `int`

**Сложность работы:** O(n), n - количество знаков до запятой.

## newl

Функция `newl` переводит на новую строчку в выводе.

**Стандартный вид:**

`newl`

**Пример:**

```bash
func main
  print "Hello, World!"
  newl
  print 123
endf
```

Вывод:

```
Hello, World!
123
```

**Ошибки:**

- Передан какой-либо аргумент.

**Сложность работы:** O(1)
