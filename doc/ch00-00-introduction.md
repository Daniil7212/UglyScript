# Введение

## Что такое UglyScript?

UglyScript - это максимально костыльный функциональный язык программирования, написанный на C++ 20. Создан в первую очередь для решения задач по спортивному программированию. А также практически всё в языке работает в виде функции.

Имеет достаточный функционал: ввод, вывод, переменные, арифметика, логические операции, условные конструкции, циклы, массивы и функции.

## Как читать документацию?

Папка ```doc``` содержит файлы с расширением ```.md```, которые и представляют собой "страницы" документации. Файлы отсортированы в порядке прочтения.

Каждый файл имеет название в формате ```ch[номер главы]-[номер подглавы]-[название подглавы (или главы в случае нулевой подглавы)]```.
