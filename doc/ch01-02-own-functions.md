# Собственные функции

По аналогии с функцией `main` вы также можете создать собственную функцию.

Например:

```bash
func f

endf
```

А также вы можете вызвать эту функцию.

Пример кода:

```bash
func f
  print "Hello, UglyScript!"
endf

func main
  print "Hello, World!"
  f
endf
```

Теперь давайте разберём ещё парочку функций.

## Содержание

- [pass](#pass)
- [exit](#exit)

## pass

Функция `pass` не делает ничего.

**Стандартный вид:**

`pass`

**Пример:**

```bash
func f
  pass
endf
func main
  print 123
  f
endf
```

Вывод:

```
123
```

**Ошибки:**

- Передать некоторый аргумент.

**Сложность работы:** O(1)

## exit

Функция `exit` полностью останавливает работу кода.

**Стандартный вид:**

`exit`

**Пример:**

```bash
func main
  println 1
  exit
  println 2
endf
```

Вывод:

```
1
```

**Ошибки:**

- Передать некоторый аргумент.

**Сложность работы:** O(1)
