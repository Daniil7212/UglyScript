## get

Функция `get` берёт элемент по индексу и записывает в переменную.

**Стандартный вид:**

`get var vec i`

- `var` - имя переменной, в которую сохранится элемент.
- `vec` - имя переменной вектора (или `string`), из которого нужно брать элемент.
- `i` - значение или переменная (типа int), обозначающая индекс.

**Пример:**

```bash
func main
  vector int v
  push v 1
  push v 7
  push v 5
  create int a
  get a v 1
  println a
endf
```

Вывод:

```bash
7
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Индекс выходит за границы объекта.

**Сложность работы:** O(1)

## insert

Функция `insert` добавляет в вектор элемент в определённое место.

**Стандартный вид:**

`insert vec i e`

- `vec` - имя переменной вектора (или `string`), в который будем добавлять элемент.
- `i` - значение или переменная (типа int), обозначающая индекс места, куда нужно вставить элемент.
- `e` - значение или переменная (того же типа что и тип вектора), которую нужно вставить в вектор.

**Пример:**

```bash
func f
  println i
endf
func main
  vector int v
  push v 1
  push v 7
  push v 5
  insert v 1 3
  foreach i v f
endf
```

Вывод:

```bash
1
3
7
5
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Индекс выходит за границы объекта.

**Сложность работы:** O(n), где n - размер вектора.

## change

Функция `change` изменяет в векторе элемент по его индексу на новое значение.

**Стандартный вид:**

`change vec i e`

- `vec` - имя переменной вектора (или `string`), в котором будем изменять элемент.
- `i` - значение или переменная (типа int), обозначающая индекс элемента, который нужно менять.
- `e` - значение или переменная (того же типа что и тип вектора), обозначающий новое значение элемента.

**Пример:**

```bash
func f
  println i
endf
func main
  vector int v
  push v 1
  push v 7
  push v 5
  change v 1 3
  foreach i v f
endf
```

Вывод:

```bash
1
3
5
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Индекс выходит за границы объекта.

**Сложность работы:** O(n), где n - размер вектора.

## erase

Функция `erase` удаляет элемент вектора по его индексу.

**Стандартный вид:**

`erase vec i`

- `vec` - имя переменной вектора (или `string`), в котором будем удалять элемент.
- `i` - значение или переменная (типа int), обозначающая индекс элемента, который нужно удалить.

**Пример:**

```bash
func f
  println i
endf
func main
  vector int v
  push v 1
  push v 7
  push v 5
  erase v 1
  foreach i v f
endf
```

Вывод:

```bash
1
5
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Индекс выходит за границы объекта.

**Сложность работы:** O(n), где n - размер вектора.
