## equal

Функция `equal` проверяет на равенство два значения и записывает результат в переменную типа `bool`.

**Стандартный вид:**

`equal name a b`

- `name` - имя переменной (имеет тип `bool`), в которую нужно будет сохранить результат.
- `a` - некоторое значение или переменная (имеет любой тип данных), которое будет использоваться в сравнении.
- `b` - некоторое значение или переменная (имеет любой тип данных), которое будет использоваться в сравнении.

**Пример:**

```bash
func main
  create int a
  create int b
  set a 10
  set b 10
  create bool ans
  equal ans a b
  print ans
endf
```

Вывод:

```
true
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- У `a` и `b` разные типы данных.

**Сложность работы:** O(log n), где n - количество всех переменных.
