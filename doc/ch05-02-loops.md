# Циклы

Циклы в UglyScript тоже являются функцией.

## Содержание

- [while](#while)
- [for](#for)
- [foreach](#foreach)

## while

Функция `while` является циклом, который выполняет некую функцию, пока определённая булевая переменная равна `true`.

**Стандартный вид:**

`while var f`

- `var` - имя переменной (имеет тип `bool`) от которой будет зависить, продолжит ли выполнение функция.
- `f` - функция, которая будет выполняться во время цикла.

**Пример:**

```bash
func f
  println i
  plus i i 1
  <= b i 5
endf
func main
  create int i
  create bool b
  
  set i 1
  <= b i 5
  while b f
endf
```

Вывод:

```
1
2
3
4
5
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Использование несуществующих функций.

**Сложность работы:** O(n), где n количество итераций цикла.

## for

Функция `for` является циклом, который перебирает диапазон чисел, записывает в переменную и выполняет некую функцию.

**Стандартный вид:**

`for var l r f`

- `var` - имя переменной (имеет тип `int`) в которой будет хранится текущее число из диапазона.
- `l` - значение или переменная (имеет тип `int`) обозначающая начало диапазона включительно.
- `r` - значение или переменная (имеет тип `int`) обозначающая конец диапазона включительно.
- `f` - функция, которая будет выполняться во время цикла.

**Пример:**

```bash
func f
  println i
endf
func main
  create int i
  
  for i 1 5 f
endf
```

Вывод:

```
1
2
3
4
5
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Использование несуществующих функций.

**Сложность работы:** O(r - l), l и r - числа из аргументов.

## foreach

Функция `foreach` является циклом, который перебирает элементы некой структуры данных (`vector` или `string`)', записывает в переменную и выполняет некую функцию.

**Стандартный вид:**

`foreach i v f`

- `i` - имя переменной (имеет тип элементов структуры данных) в которой будет хранится текущий элемент.
- `v` - структура данных (`vector` или `string`) по которой будет проходиться цикл.
- `f` - функция, которая будет выполняться во время цикла.

**Пример:**

```bash
func f
  println i
endf
func main
  create string s
  set s "hello"
  
  foreach i s f
endf
```

Вывод:

```
h
e
l
l
o
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Использование несуществующих функций.

**Сложность работы:** O(n), где n - количество элементов в структуре.
