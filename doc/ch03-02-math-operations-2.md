## abs

Функция `abs` считает модуль некоторого числа и записывает результат в некую переменную.

**Стандартный вид:**

`abs name a`

- `name` - имя переменной (имеет тип `int` или `float`), в которую нужно будет сохранить результат.
- `a` - некоторое значение или переменная (имеет такой же тип, что и переменная `var`), которое будет использоваться в операции.

**Пример:**

```bash
func main
  create int a
  set a -7
  abs a a
  println a
endf
```

Вывод:

```
7
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.

**Сложность работы:** O(a), где a - количество цифр в числе.

## pow

Функция `pow` возводит число в степень и записывает результат в некую переменную.

**Стандартный вид:**

`pow name a b`

- `name` - имя переменной (имеет тип `float`), в которую нужно будет сохранить результат.
- `a` - некоторое значение или переменная (имеет тип `float`), которое будут возводить в степень.
- `b` - некоторое значение или переменная (имеет тип `float`), обозначающая в какую степень будет возводиться.

**Пример:**

```bash
func main
  create float a
  pow a 2.0 10.0
  println a
endf
```

Вывод:

```
1024.00000
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.

**Сложность работы:** O(a + b), где a - количество цифр в первом числе, b - количество цифр во втором числе.

## sqrt

Функция `sqrt` считает корень из числа и записывает результат в некую переменную.

**Стандартный вид:**

`sqrt name a`

- `name` - имя переменной (имеет тип `float`), в которую нужно будет сохранить результат.
- `a` - некоторое значение или переменная (имеет тип `float`), из которого будет браться корень.
- 
**Пример:**

```bash
func main
  create float a
  sqrt a 9.0
  println a
endf
```

Вывод:

```
3.00000
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.

**Сложность работы:** O(a), где a - количество цифр в первом числе.
