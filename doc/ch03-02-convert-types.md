## to_int

Функция `to_int` преобразует в тип `int` и записывает результат в некую переменную.

**Стандартный вид:**

`to_int name a`

- `name` - имя переменной (имеет тип `int`), в которую нужно будет сохранить результат.
- `a` - некоторое значение или переменная (имеет тип `string`, `float` или `bool`), которое будет использоваться в операции.

**Пример:**

```bash
func main
  create int ans
  
  create string a
  set a "100"
  to_int ans a
  println ans
  
  create bool b
  set b "true"
  to_int ans b
  println ans
  
  create float c
  set c 1.33
  to_int ans c
  println ans
endf
```

Вывод:

```
100
1
1
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Невозможно преобразовать некоторые значения в `int`

**Сложность работы:**

При работе со `string`: O(log n + m), где n - количество всех переменных, m - длина строки.

При работе с `float`: O(log n + m), где n - количество всех переменных, m - количество цифр перед запятой.

В других случаях: O(log n), где n - количество всех переменных, a - количество цифр в первом числе, b - количество цифр во втором числе.


При работе с `int`: O(log n), где n - количество всех переменных
