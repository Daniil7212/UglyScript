## if

Функция `if` проверяет некое булевое значение на истину и в зависимости от этого выполняет одну из двух функций.

**Стандартный вид:**

`if var f g`

- `var` - имя переменной (имеет тип `bool`) в зависимости от значения которой будет выполняться одна из функций.
- `f` - функция, которая будет выполняться, если переменная `var` равна `true`.
- `g` - функция, которая будет выполняться, если переменная `var` равна `false`.

**Пример:**

```bash
func f
  print "more"
endf
func g
  print "less"
endf
func main
  create int a
  create int b
  create bool ans
  
  set a 21
  set b 12
  > ans a b
  if ans f g
  
  set a 101
  set b 213
  > ans a b
  if ans f g
endf
```

Вывод:

```
more
less
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Использование несуществующих функций.

**Сложность работы:** O(log n), где n - количество всех переменных.
