## input

Функция `input` позволяет ввести некоторое значение и сохранить в переменную. Работает как `cin` в C++.

**Стандартный вид:**

`input name`

- `name` - имя переменной в которую нужно будет сохранить введённое значение.

**Пример:**

```bash
func main
  create int a
  create int b
  input a
  input b
  println a
  println b
endf
```

Ввод:

```
1 2
```

Вывод:

```
1
2
```

**Ошибки:**

- Ввод значения с другим типом, отличным от типа переменной.
- Попытка сохранить значение в неинициализированную переменную.

**Сложность работы:**

O(n), где n - длина введённого значения.

## inputln

Функция `inputln` вводит всю строку и сохранить в переменную. Работает как `getline` в C++.

**Стандартный вид:**

`inputln name`

- `name` - имя переменной (типа `string`), в которую нужно будет сохранить.

**Пример:**

```bash
func main
  create string s
  inputln s
  println s
  inputln s
  println s
endf
```

Ввод:

```
1 2
Hello, World!
```

Вывод:

```
1 2
Hello, World!
```

**Ошибки:**

- Попытка сохранить значение в неинициализированную переменную.
- Попытка сохранить значение в переменную типа не `int`.

**Сложность работы:**

O(n), где n - длина введённого значения.

## fast_input

Функция `fast_input` отключает синхронизацию `stdio` и `iostream`. Позволяет ускорить ввод. Но лучше использовать только в спортивном программировании.

**Стандартный вид:**

`fast_input`

**Пример:**

```bash
func main
  fast_input
  create string s
  input s
  print s
endf
```

Ввод:

```
hello
```

Вывод:

```
hello
```

**Ошибки:**

- Попытка передать некий аргумент


**Сложность работы:** O(1)
