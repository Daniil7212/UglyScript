## reverse

Функция `reverse` разворачивает элементы вектора.

**Стандартный вид:**

`reverse vec`

- `vec` - имя переменной вектора (или `string`), который нужно развернуть.

**Пример:**

```bash
func f
  println f
endf
func main
  vector int v
  push v 1
  push v 7
  push v 5
  reverse v
  foreach i v f
endf
```

Вывод:

```bash
5
7
1
```

**Ошибки:**

- Использование несуществующих переменных.

**Сложность работы:** O(log n + m), где n - количество всех переменных, m - размер вектора.

## sort

Функция `sort` сортирует элементы вектора.

**Стандартный вид:**

`reverse vec`

- `vec` - имя переменной вектора (или `string`), который нужно отсортировать.

**Пример:**

```bash
func f
  println f
endf
func main
  vector int v
  push v 1
  push v 7
  push v 5
  sort v
  foreach i v f
endf
```

Вывод:

```bash

```

**Ошибки:**

- Использование несуществующего вектора.

**Сложность работы:** O(log n + m * log m), где n - количество всех переменных, m - размер вектора.

## find

Функция `find` ищет определённый элемент в векторе и записывает индекс этого элемента в переменную.

**Стандартный вид:**

`find var vec e`

- `var` - имя переменной, в которую сохранится индекс элемента.
- `vec` - имя переменной вектора (или `string`), в котором нужно искать элемент.
- `e` - значение или переменная (типа int), обозначающая элемент, который нужно найти.

**Пример:**

```bash
func main
  vector int v
  push v 1
  push v 7
  push v 5
  create int a
  find a v 5
  println a
  find a v 10
  println a
endf
```

Вывод:

```bash
2
-1
```

**Ошибки:**

- Использование неверных типов данных.
- Использование несуществующих переменных.
- Индекс выходит за границы объекта.

**Сложность работы:** O(log n + m), где n - количество всех переменных, m - размер вектора.
