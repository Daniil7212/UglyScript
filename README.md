# UglyScript v1.0

UglyScript - это максимально костыльный функциональный язык программирования написанный на C++. Имеет достаточный функционал: ввод, вывод, переменные, арифметика, логические операции, условные конструкции, циклы, массивы и функции.

## Установка

1. Клонируйте репозиторий или скачайте архив:
    ```bash
    git clone https://github.com/Daniil7212/jarvis.git
    ```
2. Откройте проект в CLion (в теории можно и в Visual Studio).
3. Запустите проект.
4. В файле ```input.txt``` пишите свой код.
